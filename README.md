## Overview

Obsidian Calendar adds a monthly calendar sidebar panel that links each day to a daily note, shows weekly notes, highlights dates with existing entries, and navigates the vault by date.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Obsidian Calendar** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Calendar Panel** | Monthly calendar in the sidebar with day and week note indicators |
| **Daily Notes** | One-click creation or navigation to the daily note for any date |
| **Weekly Notes** | Optional weekly summary notes linked from calendar week numbers |
| **Dot Indicators** | Visual dot markers on dates with existing notes for quick scanning |
